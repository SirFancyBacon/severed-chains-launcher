# Severed Chains Launcher

A cross-platform launcher and mod manager for [Severed Chains](https://github.com/Legend-of-Dragoon-Modding/Severed-Chains), the reverse-engineered PC port of *The Legend of Dragoon*. 


## Key Features

* **Easy Installation & Updates:** Download and extract the latest Severed Chains engine development release with the click of a button. The launcher also features a self-updater that displays when updates are available for it.
* **Integrated Mod Manager:** Browse, install, toggle, and update community mods directly from GitHub.
* **Laptop GPU Optimization:** Includes a built-in shim to force dual-GPU systems to utilize their high-performance discrete graphics card (or integrated card for battery saving)
* **Live Community Hub:** Features an integrated RSS feed for LegendofDragoon.org news and a live changelog pulled directly from the Severed Chains GitHub repository.
* **Steam Deck & Linux Ready:** Needs testing.

## Setup Instructions

1. Download the latest release for your operating system (Linux, MacOS, or Windows).
2. Extract the launcher to a dedicated folder.
3. Run the executable. If the Severed Chains engine is not detected, the launcher will prompt you to download and install it with the click of a button.
4. Place your 4 legitimate *Legend of Dragoon* disc dumps into the `isos/` folder created in the root directory. 
**Note:** All four files must share the same format (either all `.iso` or all `.bin`).
5. Launch the game.


This project was built on Godot 4
