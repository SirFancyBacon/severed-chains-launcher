# Severed Chains Launcher

A cross-platform launcher and mod manager for [Severed Chains](https://github.com/Legend-of-Dragoon-Modding/Severed-Chains), the Fan Made PC Engine port of *The Legend of Dragoon*. 


## Key Features

* **Easy Installation & Updates:** The launcher features a self-updater that displays when updates are available for it
* **Severed Chains Installation:** Install Severed Chains latest github release directly from the launcher
* **Integrated Mod Manager:** Browse, install, toggle, and update community mods. Custom Repository and Local Zip file support.
* **Laptop GPU Optimization:** Includes a built-in shim to force dual-GPU systems to utilize their high-performance discrete graphics card (or integrated card for battery saving)
* **Live Community Hub:** Features an integrated RSS feed for LegendofDragoon.org news and a live change log pulled directly from the Severed Chains GitHub.
* **Steam Deck & Linux Ready:**

## Setup Instructions

1. Download the latest release for your operating system (Linux, MacOS, or Windows).
2. Extract the launcher to a dedicated folder.
3. Run the executable. If the Severed Chains engine is not detected in the folder `severed-chains-stable`, the launcher will prompt you to download and install it with a button above `launch`.
4. Place your 4 legitimate *Legend of Dragoon* disc images into the `isos` folder; after Severed Chains is installed there will be a pop up; or in the `Misc` tab you can click `Open isos Directory`. 
**Note:** All four files must share the same format (either all `.iso` or all `.bin`).
5. Once finished click `Launch` to enjoy Severed Chains!.


This project was built on Godot 4
